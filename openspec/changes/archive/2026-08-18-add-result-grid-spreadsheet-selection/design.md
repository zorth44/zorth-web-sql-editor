## Context

SQL 执行结果和表对象 Data 页都渲染 `ResultGrid`。当前选中态是单个 `{ row, col }`：单击改焦点、方向键移动、`Ctrl/⌘C` 只复制当前格。行高亮只出现在已选中行，单元格没有 hover。列头单击循环排序，右键可复制单元格/整行，底栏可复制整表并导出 CSV。网格已做行虚拟化、列宽拖拽、固定列和客户端排序/筛选。

这套交互够「看结果」，不够「当数据表用」。CloudBeaver 一类编辑器的预期是：指针划过有行/格反馈，拖拽框出矩形，选区按 TSV 复制。本变更只改前端网格，不改执行/导出 API，也不换表格库。

## Goals / Non-Goals

**Goals:**

- 指针在结果网格上移动时高亮当前行和当前格。
- 支持拖拽矩形选区、Shift 从锚点扩展、点行号选整行、点列头选整列。
- `Ctrl/⌘C` 和右键复制当前选区为可贴进电子表格的 TSV。
- SQL 结果页和表 Data 页同时具备上述能力。
- 保留值面板、排序/筛选/固定列、整表复制和 CSV 导出。
- 选区计算与 TSV 序列化可单测，不依赖完整组件挂载。

**Non-Goals:**

- 不引入 Handsontable、AG Grid 或其他表格运行时。
- 不实现单元格编辑、填充柄、多块不连续选区、带表头的选区复制选项。
- 不改 Properties 页的 HTML 属性表。
- 不改后端结果编码、行上限或 CSV 导出契约。

## Decisions

### 1. 继续扩展现有 `ResultGrid`，抽出选区纯函数

选区模型、坐标命中和 TSV 生成放到 `web/src/components/result-grid/` 下的可测试模块（例如 `selection.ts`），`ResultGrid.vue` 只负责指针/键盘和渲染。表 Data 页已嵌入该组件，不必分叉。

备选是换成现成 spreadsheet 组件。会引入第二套虚拟化/主题/键盘模型，和现有固定列、值面板、列类型标记冲突，因此不采用。

### 2. 选区是带锚点的单个矩形

状态为：锚点 `(row, col)`、焦点 `(row, col)`、由二者导出的闭区间矩形。行坐标使用当前过滤/排序后的可见行下标；列坐标使用当前视觉列顺序（含固定列重排），复制时按视觉顺序输出。

新结果到来时清空选区，与现有 `resetView()` 一致。

### 3. 拖拽用坐标命中，而不是只听可见单元格 mouseenter

网格是虚拟化的。`pointerdown` 在格子或行号上开始拖选，`setPointerCapture` 后按指针位置、滚动偏移、行高和列宽换算目标格，这样快速拖动或拖选时滚动都不会丢格。列宽拖拽手柄、单元格菜单和右键菜单不启动选区。网格设置 `user-select: none`，避免原生文字选择抢手势。

### 4. 列头单击改成选列，排序改走类型标记和右键

现状是单击列头循环排序。若继续占满整列头，就无法「点列头选整列」。改为：

- 单击列头主体：选中该列全部可见行。
- 单击类型标记或已有排序图标：循环排序（升序 → 降序 → 取消），保留一键排序。
- 右键排序/筛选/固定列不变。
- 从列头拖出：按视觉列扩展为多列选区。
- 单击行号：选中该行全部列；在行号上拖动：选连续多行。

### 5. 复制选区使用屏幕展示文本，TSV 不含表头

`Ctrl/⌘C` 和右键「复制选区」把矩形内每个单元格的 `displayCell` 结果用 `\t` / `\n` 拼接写入剪贴板。`NULL` 复制为 `NULL`，空字符串复制为空字段，二进制复制为现有 `BINARY · N bytes` 文案。选区复制不带列名；底栏整表复制仍带表头。单格选区时行为与现在的复制单元格相同。Shift + 方向键扩展选区。

悬停高亮弱于选区高亮：未选中的行/格用 hover 底色，落入选区的格子用选区底色，焦点格保留现有 inset 边框。

## Risks / Trade-offs

- [列头单击不再直接排序，习惯点击表头排序的人会觉得变了] → 类型标记始终可见且仍一键排序，右键排序保留；在列头 `title` 中说明。
- [大结果上拖出整表选区再复制会卡主线程] → 选区只覆盖已返回且经过滤的行；复制同步拼接，超大选区时浏览器可能短暂停顿，不另做 Worker。
- [虚拟化命中算错会选到错行/错列] → 命中与 TSV 用同一套纯函数，单测覆盖固定列、滚动偏移和过滤后行号。
- [固定列与横向滚动叠加时 sticky 命中容易偏] → 命中按视觉列宽累加，并覆盖 pinned 列用例。

## Migration Plan

纯前端行为变更，无数据迁移、无 API 版本。随前端发布即可；回滚即回退该网格改动。

## Open Questions

无。不连续多选和「复制时带列名」若后续需要，另开 change。
